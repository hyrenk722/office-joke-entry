One joke about office life, one line — 116 characters, plain text.

> I replied-all to say 'please stop replying-all' and now I'm the reason there's a company-wide policy named after me.

## Run it

```sh
mkdir -p out && MAKEFUN_OUTPUT_DIR=out python3 main.py
```

The program writes the line to `/output/entry.txt` (or
`$MAKEFUN_OUTPUT_DIR/entry.txt`) with no network access; two runs write
identical bytes.
